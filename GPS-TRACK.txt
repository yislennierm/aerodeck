AERODECK — GPS-TRACK-20261018
Local GPS Track repair. Radio installation has not changed.

Failure
The browser's old ATTITUDE-PERF build aborted in GPS > Track with a native
CPU-limit error. Each refresh recalculated exact distance, bearing and pixel
coordinates for every history point. Short visits with a young trail missed
this failure; the cost grew with the trail. The original native baseline
reproduces it at roughly50 points, before the configured180-point maximum.
GPS Details/Quality/Satellites/Recovery use different bounded renderers.

Repair
- Painting uses a completed pixel path, with native clipping and one color
  setup. It still draws all179 segments for a180-point trail on every refresh.
- An at-most180-entry cache stores exact geodesic projections keyed to the
  immutable session points and frozen origin. The latest fixed-home point is
  primed during the existing session service, without scanning the trail.
- Cold origin/zoom/history changes rebuild in bounded callbacks: at most2 new
  projections and16 total points per step. The start-only callback captures at
  most180 references. No history points are dropped or approximated.
- A completed path remains visible until the next coherent path is ready.
  The aircraft uses live current GPS against that displayed path's origin and
  scale. No-home origin movement cannot repeatedly cancel an unfinished job.
- Unfinished work can reserve one FC-dispatch-free callback after200ms without
  progress. A separate attempt timestamp prevents a blocked map from starving
  the dispatcher. RF guards are freshly read when it resumes.
- New home, session/model reset and track replacement invalidate the old plot.
  Manual Set Home clears it immediately even if the next rebuild must wait.
- Rolling180-point buffers are detected through endpoints and owner identity,
  not length alone. Zoom/range labels share the completed frame's scale.
- The native20000 instruction allowance, pre-render25% guard and full widget
  buffer repaint remain unchanged. No forced garbage collection or new module.

Validation
The source-bound reports run56 portable suites under LuaJIT and stock Lua5.3
with int32/float32 numbers. The helper checks exact pixel equality with the old
geodesic algorithm, all3 zooms,180 points, cache bounds,260 rolling appends,
atomic publication, changing no-home positions, invalid coordinates, poles and
antimeridian crossings. Actual-app checks grow real session history off-page,
enter Track late, draw the complete trail repeatedly, zoom, set home, lose GPS,
and exercise retained callbacks with restricted work margins.
