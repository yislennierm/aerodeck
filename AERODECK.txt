OPEN / INSTALL
Open SYS > Tools > AERODECK. For a home-screen widget, add AERODECK through
EdgeTX widget setup and choose Full screen; it loads the same telem.lua app.
The compact widget shows live pack voltage/current/link quality. Compact or
hidden mode stops the full app, its alarms, MSP and local session timer.

To install, exit the app and merge only SCRIPTS/WIDGETS into the SD root.
Preserve settings-*.cfg, battery-*.cfg and their backups. Do not replace MODELS
or RADIO. Remove stale app caches only after backing up the existing app:
SCRIPTS/TOOLS/telem.luac and SCRIPTS/TOOLS/AERODECK/arm-status.luac, if present.
Then reopen AERODECK. This local revision has not been installed.

NAVIGATION
Six stable icon sections with 30 px Material images, in the same touch/PAGE order:
  Flight: Instruments, Arm Info (arming-block reasons)
  Data: Telemetry, Power, RC Link
  GPS: Details, Track/Home
  Video: saved VTX frequency references
  Setup: named settings categories
  Tools: Stick Guide, Sensors, Diagnostics
SYS short press focuses the same six-icon bar. Rotary or PAGE moves its focus;
ENTER opens; RTN cancels. PAGE outside that mode changes section directly.
Clock/model text uses centered native font metrics, with TINSIZE for the model.
The selected/focused navigation plates are 44 × 32 px. Detail tabs center native 18 px
symbols and labels inside 26 px context frames outside the Flight root. Flight's
compass uses the full 324 px header width; Arm Info is in the shared footer.
Other editable SVGs: development/icons/material/masters/.
The home image returns to Flight. Its editable SVG is development/icons/home-outlined-30.svg;
radio asset: SCRIPTS/TOOLS/AERODECK/icons/home.png, 30 × 30 opaque RGB PNG mask.
Replace the PNG and exit/reopen to reload; grey smooths edges and Lua supplies colour.
The home symbol returns to Flight. There is no separate twelve-tile chooser.
A section opens its stable root instead of an unpredictable remembered subpage.

On normal pages turn the rotary to focus a visible tab/action, then ENTER. ENTER
with no focus highlights an available control first. Focus remains for repeat
actions such as Zoom, Mode and Refresh. Arm Stops uses rotary to select its
reason list. Touch works on the corresponding visible controls.

RTN backs out of a detail to its owner, then Flight. From Setup it first cancels
an active value edit, then returns to categories, then the originating page.
Short RTN on Flight exits; unsaved drafts offer Keep Editing or Discard/Exit.
Held RTN is EdgeTX's firmware-controlled forced exit.

All twelve pages share one 26 px footer: flight mode, app-local home distance,
satellites, a current arming-block summary, and a separate 48 px Arm Info icon.
The mode has no repeated FM prefix. LQ, RSSI and voltage are not repeated here.
Missing sensor values show --. A fresh supported mask shows the first reason
code plus the number of additional reasons. NO FLAGS means only that the
reported disable mask is clear; it never claims READY or ARMED. FLAGS -- means
unavailable, STATUS OLD means stale, and STATUS ERROR means malformed status.
Unknown API/count combinations retain numbered bits.

The rightmost Arm Info icon remains visible during warnings and notices.
Warnings occupy the left 432 px; touch or focused ENTER opens their details.
The separate right icon opens the read-only reason list on normal or warning
pages. RTN returns to the originating page and preserves an active Setup value
edit and draft. From the first Setup category, PREV can focus the footer icon.
Normal mode/home/satellite/status readings remain informational.

SETTINGS
Select a category with rotary/ENTER or touch. Existing protocol/FC/source/VTX
conditions determine available categories; hidden values remain saved.
Choose an editable row, ENTER, adjust with rotary, ENTER to finish the draft.
RTN during editing restores that one value. Touch a row and use -/+ to adjust.
Rotary also reaches Save, Revert and More Rows; notes are not editable.
SAVE SETTINGS commits the shared non-battery draft. SAVE BATTERY commits only
cell count/voltage/alert preferences. Their pending badges are independent.
A save validates, writes and verifies the file, retaining the previous values
as a backup. Saving one store does not commit the other. Notes-only categories
have no editing/save buttons. See UX-CLEANUP.txt for the complete control model.

Preferences use settings-<hex-model-name>.cfg and battery-<hex-model-name>.cfg
inside SCRIPTS/TOOLS/AERODECK. Renaming a model selects different settings;
duplicate names share preferences. These are app settings, not FC/output writes.
Legacy RC/FC profile None still permits automatic native CRSF detection; use
the real Read-only FC connection Off control to disable MSP.

FLIGHT PAGE
Designed for the user's reported 30–40 cm viewing distance. Native font sizes
are measured; physical readability has not been measured on the radio.
The battery rail prioritizes pack voltage, consumed mAh and current with 29 px
values when they fit. Derived AVG CELL V moves to the 17 px bottom slot; it is
pack voltage divided by configured cells, not an individual cell measurement.
Battery comparisons round per-cell voltage to 0.1 mV before checking the saved
0.1 V thresholds. This fixes an ABOVE MAXIMUM false warning for an exact full
pack caused by native float32 roundoff. Saved values and alarm policy are unchanged.
The link rail uses 29 px LQ, RSSI and SNR values; TX mW moves to the 17 px
supporting slot. Longer values still use measured fitting rather than overlap.
Estimated percentage retains its ~ prefix. Its bar accommodates the measured
percentage label, including ~100%, without crossing the separator.
Missing readings and their status icons are muted. The link icon follows the
actual configured LQ thresholds; the battery icon turns orange on a warning.
The 232 × 180 visible attitude field, full HUD, aircraft datum, tapes, rails and
six navigation icons retain the preceding build's geometry and priorities.
Removing the header ARM INFO text button returns all 324 px above the HUD to
the compass. Arm Info is now the persistent icon-only footer control; it does
not arm the quad. The global footer replaces the old per-page status footers.
See FLIGHT-STATUS.txt for this revision and FLIGHT-GLANCE.txt for HUD geometry.

DATA / CAPABILITIES
Production telemetry is live-only. Missing/stale values show --; unavailable
attitude is masked rather than shown as level flight. No demo fixture ships.
The full app uses telemetry-qualified cached source IDs and unit conversions.
Discover sensors in the radio's Telemetry menu and map custom names in Setup.
Telemetry has 27 current display slots, not 27 guaranteed sensors or Min/Max.
Cell average is pack voltage/configured cells, not individual measured cells.
Capacity-based remaining is labelled estimated and assumes a full pack with
reset consumption. Power/RC traces retain up to 90 foreground samples.

GPS shows current coordinates, satellites, speed, altitude, course and local
home distance/bearing. Track is a north-up relative plot, not a map. Local home
does not alter FC home. Satellite count does not prove a 3D fix. Home capture
and track sampling still run only on GPS pages; this is not continuous logging.
GPS-source changes do not yet invalidate old home/history automatically.

Arm Info decodes current STATUS_EX flags for exact verified API/count pairs:
1.46/26, 1.47/29 and stable Betaflight 2026.6.2 API 1.48/30. API 1.48 names GPS
at bit 18, AUTOPILOT_SW at bit 28 and ARM_SWITCH at bit 29 (zero-based).
GPS Rescue requires a valid fix and the configured minimum satellite count;
the explanation does not infer a fix from satellites alone. Unknown APIs or
counts, including API 1.49, retain numbered bits rather than guessed names.
Decoding is cached per status reply; footer and list share the same eight-second
freshness rule. Stale, malformed, unavailable or stopped status clears current
reasons. A clear mask proves neither readiness nor armed state. Radio switch
arm/cut indicators and the local arm stopwatch remain separate from FC state
and EdgeTX timers.

Stick Guide contains 12 reference diagrams in modes 1–4; it sends no commands.
Video shows eight offline frequency notes, common band labels and a live
attitude inset. There is no connected VTX status/table/power/PIT/Apply/Save.

The existing bounded read-only CRSF MSP loop is unchanged: identify Betaflight,
then status every 3 seconds only with explicitly disarmed current FM and
eligible link/profile settings. It stops for armed/unknown/stale/failsafe/off
states. No automatic runtime SD logging or FC/RF/model/output writes are
introduced. Details: TELEMETRY-CONNECTION.txt; source/feature audit under
development/assessments/.
