CONTROLS
Six top icons: Flight, Data, GPS, Video, Setup, Tools. PAGE cycles sections.
Short SYS/MDL focuses the bar; rotary chooses and ENTER opens. On a page, rotary
focuses visible tabs/actions, ENTER activates and RTN backs out. Touch uses the
same controls. The home icon returns to Flight.
Hold SYS for global Quick Actions: mute/unmute, confirmed Flight Data reset,
conditional Restart MSP, conditional Read VTX Tables, and Reload AERODECK.
Reload reinitializes local state/settings; close/reopen after changing source.
Flight's PFD/VIDEO/GPS control changes its centre panel; Setup > User Interface
chooses the saved default, COG versus YAW compass, and Minimal/Graduated marks.
The shield at the footer's right opens Arm Info and returns to its origin.

WIDGET STARTUP AND RECOVERY
First widget startup shows loading/progress through 13 bounded initialization
phases, including native inputs, compiled source plans, FC client and arming
decoder. Wait for the normal screen before using page controls. Source refresh also advances incrementally while retaining the
flight session/home. A background SESSION ERROR suspends that instance; use the
EdgeTX widget Update action to retry controlled closure/restart. A failed timer
restoration keeps its original session metadata rather than replacing it.

CONNECT REAL DATA
Select the actual protocol/FC in Setup > Model Setup. Auto uses profile defaults;
it is not a hardware discovery claim. Discover telemetry sensors in EdgeTX,
then use Sensors or Power > Refresh. Auto selects the profile's native aliases;
None explicitly disables a quantity. Power shows LIVE, STALE, INVALID, NOT FOUND
or OFF and offers Sources/Refresh/Limits actions. Missing values remain --.
FC diagnostics shows the actual variant/API/version/board/UID/sensor health.
Video reads real reported settings; choosing a channel/favourite is a proposal.
Apply is the explicit configuration write and waits for acknowledgement/readback.

NATIVE TIMER OWNERSHIP
RADIO host preserves the timer. Explicit AERODECK host uses an ADxxxxxx native
timer-name lease, blocks another owner and restores captured settings on a
controlled exit. An abrupt abort can leave a stale marker; review/reconfigure the
native timer and rename it before reclaiming. Clearing the marker cannot recover
the lost in-memory configuration snapshot. See AERODECK.txt for recovery details.

WIDGET REFRESH
Every scheduled native widget refresh paints a frame; the native LCD buffer is
transient. Slow data uses four bounded phases: two field-acquisition batches,
power derivation, then session/publication. Acquisition starts target a 200 ms
period. At 20 callbacks/s, fields span about 50 ms and publication follows about
150 ms after the first batch. Only completed work becomes visible; cancellation
never edits the displayed sample. Normal callbacks read current pitch/roll.
The render-rate setting targets the standalone tool, whose buffer persists;
it is not a widget callback limit. First-sample or exceptional
heavy-action work paints an opaque progress screen, never a blank frame.
Under load, slow phases wait for headroom while the cached screen and fresh
attitude still paint. Sampling temporarily takes priority over transport after
400 ms without publication or 200 ms of pending work. These are fairness
thresholds, not a guarantee of data age or physical refresh rate.
