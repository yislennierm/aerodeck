ON EACH COMPUTER
1. Make this entire LUA folder available locally through your chosen sync or Git workflow.
2. Install EdgeTX Companion for that computer and select the TX16S radio type.
3. Set Companion's SD-card folder to the sdcard folder inside this local project.
   That absolute path is specific to each computer; it is not an editor setting.
4. Start the radio simulator and open SYS > Tools > AERODECK.
5. Edit telem.lua, save, then exit and reopen AERODECK to reload.

The .code-workspace uses relative paths. Lua bitmap paths beginning /SCRIPTS
are SD-card-root paths and must stay that way for the radio.

This move does not configure cloud sync or a Git remote. Use the folder's
existing sync service if available. Avoid editing the same file concurrently
on two computers. Install archives are snapshots; edit the source under sdcard.
