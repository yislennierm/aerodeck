Changes
- Standalone full telemetry/session work honors its existing200ms/revision cache
  instead of being forced at every redraw. Attitude still polls every callback.
- Native font metrics use a bounded128-caption FIFO.32 value cells retain only
  their most recent fitted layout. Live colors, values and units stay current;
  font/LCD/geometry changes invalidate the appropriate cached metrics.
- Removed two per-frame temporary arrays and repeated horizon-origin work.
- Retained startup loads one of20 native icon variants per callback, before the
  first full frame. Successful and failed assets stay cached across pages and
  same-resolution reloads. No forced GC at icon loading/page navigation.
- Retained MIN/MAX reads move out of painting. Up to4 qualified native fields
  are read/normalized per scheduled step, using cached compiled normalizers.
  Only complete snapshots publish. Pending work cancels on LIVE/page exit/
  background/revision changes, and excessively old/rolled-back work restarts.
  Native receipt/currentness, raw Roll and negative-pitch MIN/MAX slot inversion
  remain explicit. Standalone extrema retain the synchronous API with a200ms
  cache. Retained history cadence is best-effort under the native callback budget;
  the200ms target is not a guaranteed5Hz publication rate.
- Every native widget refresh still paints its whole transient display buffer.
  The20,000 instruction hook is unchanged. No fake attitude, smoothing that
  conceals stale input, frame-repaint skipping or production sample provider.
