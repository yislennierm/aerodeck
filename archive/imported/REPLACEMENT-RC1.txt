MAIN CHANGES
- Budgeted production-widget startup: separate load/chunk/init callbacks, 13
  retained initialization phases and incremental native input discovery/refresh.
  Source plans, FC client and arming decoder receive their own cold phases.
  Startup progress is explicit; warm model changes yield before old timer/reset
  work can reach a new model. Failed background sessions have explicit Update
  recovery that retains timer-restoration metadata until closure succeeds.
- Every native widget refresh paints its transient LCD buffer. Slow work uses
  four bounded phases: first field batch, remaining fields/summary, power policy,
  then session/publication. Acquisition starts target a 200 ms period. At
  20 callbacks/s, fields span about 50 ms and publish about 150 ms after the first
  batch. Displayed values stay intact across repeated cancelled/expired work.
  Normal callbacks update current pitch/roll. Render Hz targets the tool only.
  First-sample, heavy explicit actions and exceptional FC/cache work paint opaque
  progress; ordinary sampling never intentionally skips painting a frame.
- Slow phases defer to CPU headroom while a complete cached page and fresh
  attitude continue to paint. Sampling receives transport-free callbacks after
  400 ms without publication or 200 ms of pending work; normal transport guards
  apply when it resumes. Modals can progress without drawing the hidden PFD.
  These thresholds are fairness controls, not data-age or physical-FPS promises.
  Expired/obsolete work restarts; repeated cancellation preserves the display.
- Compiled source readers retain the unchanged unit/range normalization oracle.
  Independent corpora compare 1,912,664 inputs per interpreter; this establishes

NATIVE TIMER OWNERSHIP
RADIO host leaves native timer configuration alone. Explicit AERODECK host uses
a native ADxxxxxx name lease across independently loaded app/widget instances,
so a second claim cannot reset an occupied timer. Controlled release restores
the captured configuration, then its original name; elapsed time is not restored.
Failures retain the lease and in-memory retry information. An abrupt abort/model
switch can leave a stale lease whose original configuration snapshot is lost.
Review/reconfigure the native timer and rename it before reclaiming; removing
the marker alone cannot reconstruct old mode/start/beep/persistence settings.
A manual native name change revokes ownership without overwriting user changes.
