# Imported development archive

This directory preserves earlier experiments, screenshots, source-bound reports, parity audits and release notes. These are historical records, not the current build/test entry points or a fresh hardware acceptance claim.

`imported/` mirrors the original repository-relative paths. For example, the former `development/runtime-evidence/2026.10.0-alpha/` is now `imported/development/runtime-evidence/2026.10.0-alpha/`. The files themselves retain their exact bytes and original references. `index.json` records every archived file's previous path, present path, size and SHA256.

Start with the root README and CONTRIBUTING.md for current instructions. Use archived records to investigate a past decision or compare a feature with its recorded evidence. Do not rewrite frozen reports when paths or current source change. Historical references to the original computer are provenance, not current requirements.

The browser preview resolves recorded startup evidence from this archive and verifies its original hashes against the active runtime before serving it. Archived ZIPs/manifests are not automatically regenerated.
