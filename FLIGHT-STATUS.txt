SHARED FOOTER / FLIGHT SPACE
All twelve pages use the same 26 px footer at y246:
  x0–120: flight mode, without a repeated FM prefix
  x120–240: app-local home distance
  x240–304: satellite count
  x304–432: current arming-block summary
  x432–480: separate icon-only Arm Info control
The first three readings are informational and missing values remain --.
Home remains local to the app; satellite count alone does not prove a GPS fix.

Warnings occupy x0–432, leaving the right 48 px control visible and usable.
Touch or focused ENTER opens the relevant warning details or the separate
Arm Info list. RTN from Arm Info returns to its originating page, preserving
Setup category, draft and active value edit. PREV from the first Setup category
can focus the footer control. Arm Info is read-only and does not arm the quad.
If a warning clears while its Setup footer action is focused, focus returns
to the normal category controls rather than leaving rotary/ENTER stranded.

Flight no longer has an ARM INFO text button above the attitude display.
The compass reclaims the full 324 px header. HUD/rail geometry, attitude datum,
pitch direction, 1.85 px/degree scale and the preceding data priorities remain.
Normal footers no longer repeat LQ/RSSI/voltage or display persistent MSP text.

STATUS MEANING
A fresh supported status shows the first arming-disable reason code plus a
count of additional reasons. NO FLAGS means only that the received disable
mask is clear. It never claims READY or ARMED. FLAGS -- means unavailable;
STATUS OLD means the last status is stale; STATUS ERROR means it is malformed.
Unknown API/count combinations keep numbered bits rather than guessed names.
Footer and reason list share the existing eight-second freshness policy.
The decoded result is cached per received status packet, not rebuilt each frame.

BETAFLIGHT DECODER
Verified maps are exact API/count pairs 1.46/26, 1.47/29 and 1.48/30.
Stable Betaflight 2026.6.2 API 1.48 adds AUTOPILOT_SW at zero-based bit 28
and moves ARM_SWITCH to bit 29; GPS is bit 18. GPS Rescue needs a valid fix and
the configured minimum satellites. Existing API 1.46/1.47 maps are preserved.
API 1.49 and mismatched counts remain unsupported numbered fallbacks.
Official source URLs and exact release/line references are in arm-status.lua's
sources table. Tests exercise all 30 API 1.48 flags, low/high multi-bit masks,
GPS18, both older maps, malformed packets and unknown API/count combinations.
