The independent Open Location Code implementation retains its algorithm licence in `development/navigation-utils/LICENSE`. Installation packages carry it at `LICENSES/open-location-code.txt`.

The approved AD branding source, generation provenance and editable/export assets are in `development/branding/aerodeck-v2/`.

Toolbox is reference material maintained outside this product. No Toolbox activation mechanism is included. Historical comparisons and source evidence are development records, not a distribution of Toolbox as a runtime dependency.

The optional browser preview runs an externally supplied EdgeTX WASM simulator. Its licence and corresponding source belong to EdgeTX; the simulator binary is not bundled in this repository's installable runtime.

A project-wide distribution licence for AERODECK's original code has not yet been selected. Existing third-party licences remain attached to their respective material.
