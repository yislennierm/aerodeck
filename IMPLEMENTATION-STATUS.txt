OPEN ACCEPTANCE / DO NOT CLAIM COMPLETE
- All actual-app Flight banks, COG/YAW missing-source behavior, Minimal/Graduated
  marks, full date, optional model image, independent voltage/charge gauges,
  input states and five Quick Actions now have named end-to-end portable tests.
- Production-widget startup uses separate callbacks, 13 cold phases and bounded
  native input discovery/refresh. Exact-source clean native startup / all 13-page
  checks pass under the actual 20,000-instruction hook, with 27 reviewed frames.
  The ledger binds that cold gate separately from current 48-suite reports.
  Populated native evidence includes an approximately 203-second widget run;
  a 170.365-second / 4,500-sample monitor saw no blank frames, ordinary updating
  screens or instruction-limit errors under the unchanged hook. Simulator diagnostics showed
  17.2 draw FPS / distinct attitude-value Hz and 4.1–4.2 slow publications/s.
  This is synthetic EdgeTX 3.0 evidence, not target-radio/Toolbox comparison.
  The accepted complete native bundle binds each case and current source.
  DATA-103 describes the mechanism; physical performance remains unverified.
- Every scheduled native widget refresh paints its transient LCD buffer. Slow
  work spans four bounded callbacks: two field batches, power, session/publish.
  Acquisition starts target a 200 ms period. At 20 callbacks/s, field acquisition
  spans about 50 ms and publication follows about 150 ms after the first batch.
  Repeated revision/age cancellation never mutates still-displayed values.
  Normal callbacks update current attitude. Render Hz is a tool-only target.
  Slow phases can wait for instruction headroom; after published 400 ms / pending 200 ms
  thresholds, only transport is deferred to prevent sampling starvation.
  Data age/cadence can exceed the nominal values; no physical budget claim.
  Exceptional heavy work paints opaque progress, never an intentional blank.
- All 48 portable suites pass on both LuaJIT and stock Lua 5.3 int32/float32.
  Reports match all 48 test files and 64 runtime code/image hashes. Compiled
  readers match 1,912,664 oracle comparisons per VM; the retained scheduler
  passes 11,191 actual-app checks per VM, including actual-wire fairness.
  Synthetic checks do not establish physical speed or final native acceptance.
- Arbitrary damaged-module recovery is unverified. Exact-runtime native visual
  and warm gates pass as simulator evidence; target hardware still needs cold
  load, 10-minute attitude/memory, real telemetry, timer and RF-write acceptance.
- Physical FrSky/CRSF/INAV/TBS/input/display combinations remain required; no
  unavailable radio/panel success is inferred from mocks or another firmware.
- New-model defaults, flat artwork/marks and shared warning/footer layout are
  explicit configurable UI choices, not missing functional capabilities.
- Eight reference producer/reachability claims remain unsupported-reference:
  acceleration, frequency-range filtering, individual-cell arrays, flight CSV,
  use-history and persistent GPS recovery. The JSON lists all eight exact IDs.
  These are not licensing exclusions or an assertion of replacement completion.
- Native timer ownership uses an ADxxxxxx name lease across independent loads.
  Controlled release restores captured configuration/name, not elapsed time.
  Abrupt abort can lose the RAM snapshot: inspect/reconfigure the native timer
  and rename it before reclaiming. Removing a marker cannot restore old settings.
- Retained widget alerts/session work depend on EdgeTX scheduling callbacks;
  opening a standalone tool pauses widget refresh until it closes.
